# Java Generics Activity

## Step 1: Research

A few terms you should know. Research definitions for the following terms if you are unfamilar with them.

- Generics - allow us to parameterize types, allowing for code/function to work with multiple different data types. Does not work with primitives.
- Type Parameters - Placeholder like <T>, <E>, <K> used in a generic in play of a type. 
- Boxing - Process of converting a primitive data type into it's object wrapper class
- Unboxing - Process of converting an object into it's corresponding primitive
- Autoboxing - Automatic conversion between primitives and their corresponding wrapper classes when needed i.e. .ValueOf()
- Wrapper - Wraps a primitive data type into an object
- Diamond Operator - shorthand syntax in Java used to simplify the instantiation of generic classes by allowing the compiler to infer type arguments from the context.
